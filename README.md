# Just Type

This is a little typing game for practicing touch typeing. I made it for fun and it is a bit rough around the
edges, but if you like it feel free too play and contribute.

# Building

> Note: The build was not properly tested, it is more of a "it works on my machine" sitiuation :).
> That being said if you are on Linux or Darwin the nix flake should provide the necessary deps for
> building it.

```bash
# for debug builds just ommit the release flag
cargo build --release
```
